# React Fundamentals

A learning project built while following the **Fundamentals | React JS in Sinhala** playlist.

## What I learned

- Building reusable React components
- Managing component state with `useState`
- Using `useEffect` to fetch user data from the Random User API
- Setting up page navigation with React Router
- Styling and aligning the navigation bar with Bootstrap
